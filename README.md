# OrangeHRM Login Automation

Automation testing fitur Login OrangeHRM menggunakan Cypress.

## Test Cases
1. Login berhasil dengan credential valid
2. Login gagal dengan password salah
3. Login gagal dengan username salah
4. Login gagal saat username kosong
5. Login gagal saat password kosong

## Menjalankan Test

npm install

npx cypress open

atau

npx cypress run
